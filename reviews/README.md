# 在线审核提交

在审核台标记候选，点击“提交到 GitHub”。登录 GitHub 后，将 JSON 提交到新分支并创建 Pull Request。没有仓库写入权限时，GitHub 会引导创建个人 fork。

**请选择新分支并创建 PR，不要直接提交到 main。** 批次过大时，页面会下载 JSON 并打开上传页面；同样选择新分支创建 PR。

PR 会验证整个审核文件、候选 URL 身份、当前候选目录、稳定源 ID、重复 URL 和冲突决定。合并后，日常构建在抓取之前应用结果：通过项加入 sources.json，拒绝项写入公共审核记录。审核台随后可读取公共状态。拒绝决定不会删除已经正式收录的源。

文件名只使用字母、数字、短横线、下划线与 `.json` 后缀。记录格式由 `docs/api/v1/review-schema.json` 定义。这里仅存储明确提交的审核结果，不上传浏览器的其他数据。
