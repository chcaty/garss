# 嘎!RSS

## Platform

web and Android (Flutter)

## Purpose

Aggregate RSS articles for people seeking a broader information stream; provide a local-first candidate subscription workbench. Evidence: README.md, docs/API.md and docs/review.html.

## Constraints

Keep the Python collection pipeline, published API schemas, consistent snapshots, OPML compatibility, local review storage and offline review. Static HTML and native ES modules remain the stack. Original article links open publishers. Documentation stays accessible.

## Confirmed scope

The user requested overall code refactoring and page redesign, selecting warm paper and simple editorial style. Proposed scope: searchable RSS homepage and coordinated review workbench.

The user subsequently requested an Android-first app that reads GitHub Pages JSON and improves reading. The native client includes source preferences, article search, unread state, persistent bookmarks, cached summaries, optional publisher image previews and an in-app original page. Static Pages remains the content backend; no account or cross-device synchronization is promised.
